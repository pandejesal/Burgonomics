Reelo enables merchants to leverage customer data and analytics to drive incremental revenue. Our next generation customer engagement and business intelligence platform empowers merchants to acquire customers by connecting with their Point-of-Sale (POS) system and to grow their business. Over 4000 brands across 40 cities trust Reelo to transform their customer experience and engagement. With 20+ POS partner integrations, we work with restaurants, cafes, grocery &amp; departmental stores, supermarkets, salons, spa, apparel, jewelry, and various other stores. Getting Started As Reelo’s POS integration partner, you can use our APIs to allow your merchants to collect customer details, manage their loyalty points, redeem rewards, capture orders, take feedback, etc. programmatically by connecting their POS system. Note that the loyalty program will be set up by the merchants on Reelo’s dashboard. This document shows you how to get set up and start making requests to Reelo API.

Get customer loyalty details

### `POST` `{{domain}}/v1/pos/integrations/{{vendor_id}}/rewards/customer`
This url is to get all loyalty details about the customer that includes total points of customer, list of redeemable rewards. customer_key*: String customer_key is unique branch key provided by POS. merchant_id*: String merchant_id is unique branch key generated by Reelo and shared with POS. customer_mobile*: Number Valid mobile number without any country code prefixes Integration configuration- Video Tutorial Rewards configuration- Video Tutorial Combo items redemption- Video Tutorial Rs.discount on entire bill - Video Tutorial Cashback redemption- Video Tutorial
- Header: `Content-Type`: `application/json`
- Body (raw):
```json
{
   "customer_key": "xxxxxxxxxxxxxxx",
   "merchant_id": "{{merchant_id}}",
   "customer_mobile": "{{customer_mobile}}",
   "table_number": "",
   "number_of_pepole": ""
}
```

Authenticate redemption (send_otp)

### `POST` `{{domain}}/v1/pos/integrations/{{vendor_id}}/points/authenticate`
Send otp to customer to redeem points/rewards. Send otp for earning point if branch requires authentication when earn points. merchant_id *: String customer_key *: String phone *: Number Phone of customer for which the OTP is being requested. points *: Number Mandatory if loyalty type is cashback coupon_code * : String Mandatory if loyalty type is tier-based
- Header: `Content-Type`: `application/json`
- Body (raw):
```json
{
   "coupon_code": "611e053209183d3a0fed8732",  
    "customer_key": "xxxxxxxxxxxxxxx",
   "merchant_id": "{{merchant_id}}",
   "customer_mobile": "{{customer_mobile}}",
   "wallet_credits": "1200"
}
```

Send bill to Reelo (Capture Bill)

### `POST` `https://vquovg46me.execute-api.us-east-1.amazonaws.com/v1/pos/integrations/{{vendor_id}}/bill/customer`
customer_key*: String merchant_id *: String customer *: Object name : String mobile*: String Valid 10 digit mobile number starting with 6/7/8/9 along with country code email: String dob: String -&gt; Format: DD/MM/YYYY anniversary_date: String -&gt; Format: DD/MM/YYYY transaction: * Object id *: String Unique id of alpha-numeric characters number *: String Bill Number sale_return: true/false reference_bill : { id : String bill_number : String order_time : String } discount: Number type*: String Order type -&gt; dine_in/take_away/delivery/others source*: String, order source -&gt; zomato, swiggy, roomservice, online etc payment_type*: String Mode of payment-&gt; cash/card/UPI order_subtotal *: Number amount before discounts and taxes gross_amount *: Number Item total - amount after all discounts (Reelo as well as external) net_amount *: Number gross_amount + charges + taxes amount *: Number Final bill amount collected from the customer charges : Array any type of charges that you charge your customers (Eg. service charge) taxes : Array any type of taxes that you charge your customers (Eg. GST) items*: Array redemption*: Object reward_id : String id(coupon_code) of a reward that is redeemed. Mandatory for reward redemption redeemed_amount : String cashback amount that is redeemed. Mandatory for cashback redemption For any bill there will only one type of redemption either reward redemption(reward_id) or cashback redemption (redeemed_amount) order_time*: String order_from *: String table_number : String number_of_people : String POS/own_website/online_order Definitions: 1. order_subtotal: amount before all discounts, taxes and charges 2. gross_amount : item total - after all discounts (Reelo as well as external) 3. net_amount : gross_amount + charges + taxes 4. amount : net_amount 5. charges (%) : any type of charges that you charge your customers (Eg. service charge) 6. tax (%) : any type of tax that you charge your customers (Eg.
