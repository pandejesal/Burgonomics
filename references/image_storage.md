# BURGONOMICS — Cloud Image Storage & Asset Optimization (Layer 3 Constraint)

> **Reference Specification**: Google Cloud Storage bucket paths, WebP image compression, CDN caching, and food photography guidelines.

---

## 1. Storage Bucket Paths

```
gs://burgonomics-assets/
  ├── products/{productId}.webp      (Food photography, 800x800, WebP)
  ├── categories/{categoryId}.webp   (Circular category icons, 256x256)
  ├── banners/{bannerId}.webp        (Promotional banners, 1200x600)
  ├── avatars/{uid}.webp             (User profile photos)
  └── tickets/{ticketId}/{imgId}.jpg (Customer issue proof images)
```

---

## 2. Food Photography Guidelines
- 100% Pure Vegetarian gourmet burger presentation with vibrant natural lighting.
- Transparent PNG or clean white/dark background for hero cutout carousel banners.
