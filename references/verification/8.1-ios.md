### Gap 4 — Capacitor URL / universal-link handlers in AppDelegate
**Verdict: handlers existed; universal-link path skipped Capacitor bookkeeping. FIXED.**

`ios/App/App/AppDelegate.swift` already had both Capacitor 8 entry points:

- `application(_:open:options:)` (line 36-40) → already delegated to
  `ApplicationDelegateProxy.shared` ✔ (no change).
- `application(_:continue:restorationHandler:)` (was lines 42-53) → hand-rolled:
  it re-implemented the proxy body (guard on `NSUserActivityTypeBrowsingWeb`,
  post `.capacitorOpenUniversalLink` with `["url": url]`) but **never set
  `ApplicationDelegateProxy.shared.lastURL`**, which that property declares as
  `public internal(set)` and therefore cannot be set from the app target.
  `lastURL` is what `App.getLaunchUrl()` reads
  (`node_modules/@capacitor/app/ios/Sources/AppPlugin/AppPlugin.swift:98`), so a
  cold-start universal link was invisible to that API.

Change — `ios/App/App/AppDelegate.swift:42-50`: replaced the hand-rolled body
with the stock Capacitor 8 delegation
`return ApplicationDelegateProxy.shared.application(application, continue: userActivity, restorationHandler: restorationHandler)`,
which performs the identical guard + identical `["url": url]` notification post
and additionally records `lastURL`
(`node_modules/@capacitor/ios/Capacitor/Capacitor/CAPApplicationDelegateProxy.swift:19-31`).
Verified before editing that the exact method signature exists in
`@capacitor/ios` 8.5.0 (the version pinned in `package.json`), so `appUrlOpen`
delivery to `mobileBootstrap.ts` is behaviour-preserving.

### Gap 5 — Back-button behaviour is Android-only
**Verdict: no iOS defect; nothing to change (documented, not fixed).**

There is no hardware/gesture "back" event on iOS: Capacitor's iOS `AppPlugin`
exposes no `backButton` event and `App.minimizeApp()` is `call.unimplemented()`
on iOS by plugin design. The `backButton` listener in
`src/shared/platform/mobileBootstrap.ts` therefore never fires on iOS, and the
`App.minimizeApp()` branch inside it is unreachable there. iOS backs out via the
WKWebView edge-swipe (history-based, works with the SPA `pushState` router) and
in-app controls — the in-app half of plan task 8.1 is the main lane's job under
`src/`, which this sub-lane is forbidden to touch.
